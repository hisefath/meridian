# Meridian — Binary Stock Outcome Markets on Solana

Non-custodial 0DTE binary contracts on MAG7 closing prices: *"Will META close at or above $680 today?"* YES pays $1 USDC, NO pays $1 USDC otherwise, and YES + NO = $1 always.
